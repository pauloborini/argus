# TEMPLATES — modelos do vault

Pasta obrigatória da lista fechada do vault (`_app-vault/docs/TEMPLATES/`, maiúsculo).

| Arquivo | Papel |
|---|---|
| `DECISION_TEMPLATE.md` | modelo de arquivo de domínio (`docs/decisions/<dominio>.md`) |
| `DECISION_PROTOCOL.md` | protocolo operacional de decisões entregue com o pacote — identidade `DEC-NNN`, numeração, alteração in-place, remoção e promoção humana |
| `INDEX_TEMPLATE.md` | modelo do `INDEX.md` do vault (ponteiro, três seções, teto ~100 linhas) |

Quem escreve decisão lê primeiro o protocolo: `_app-vault/docs/TEMPLATES/DECISION_PROTOCOL.md`.
