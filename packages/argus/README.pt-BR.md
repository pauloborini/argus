# Argus

<!-- Idioma: [English](README.md) · **Português** -->

Code retrieval, memória local e context packing para agentes de código.
Local-first, sem UI, CLI + MCP.

```bash
npm install -g @owerride/argus
cd seu-repo
argus install
argus search "calculateTotal"
```

`argus install` prepara o índice local, o cofre de memória, o registro MCP e o
daemon de auto-sync. ListTools anuncia as cinco tools MCP recomendadas:
`explore`, `pack_context`, `recall`, `remember`, `status`. As doze tools
registradas continuam invocáveis; veja a referência completa de comandos.
